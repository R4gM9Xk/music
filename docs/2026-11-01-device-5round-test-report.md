## 1. 实锤发现明细

### F1【P0】自动切歌后首次点暂停不暂停（= 审计 P0-3 真机复现）
- 证据：`p03b_B`（《反方向的钟》自动切歌后首点暂停 @00:06 仍在播）→ `p03b_C`（2s 后 00:09 继续走秒）→ `p03b_D`（第二次点击才暂停 @00:40）
- 对照组：完播**前**手动暂停同坐标正常（`p03_B` 04:56 冻结）→ 坐标无误，专属「自动切歌后首点」场景
- 代码映射：`AppState.kt` syncFromEngine 不回写 engineLoadedUri ↔ togglePlayPause:1042 误判未装载

### F5【P1】字号变更重置睡眠定时器（= 审计 P1-3 变体①）
- 时序：10:58:25 设 15 分钟（快照 mode=15，播放中）→ 11:01:50 `font_scale 1.3` 触发 Activity 重建 → 11:13:25（原始截止）仍 armed（11:14:16 读数 mode=15，**反驳「正确剩余时间」**）→ 11:23:09 前已归零，且全程未恢复过播放（**反驳「暂停挂起倒计时」**）→ 唯一自洽解释：重建时按**整档 15 分钟**重发，新截止 ≈11:16:50
- 影响：倒计时静默延长，用户感知「到点不停」；配合 P2-26（重建弹回首页）发生得毫无提示

### F4【P2】横屏旋转（歌词模式）→ 歌词舞台空白
- 证据：`r4_03_landscape.png`（旋转后 2.5s，左舞台仅剩左上角小封面，LyricRail 无内容；顶栏/右栏控制卡/提示行布局正常）→ 横滑切封面正常（`r4_03_center_swipe.png`）→ 再切回歌词渲染正常（`r4_03_lyrics_blank.png`）
- 根因类：审计 P1-5（stage 的 weight(1f) 落 Box 父被丢弃）在旋转重组路径的又一表现；竖屏不触发

### P2-26 动态证实
- 播放页状态下改字号 → 重建后落在曲库首页（`r4_05_after_font.png`），AppState 非 Saveable 的代价实锤

### F3【量化修正】G2 玻璃透字：haze 活着，但 scrim 不够
- 边缘强度：透字 mean-grad 3.4（导航栏）/5.1（迷你条） vs 前景正常文字 21.9 vs 纯玻璃 0.13 → **有模糊但不充分**，透字语义仍可辨认 → 双重显影混乱
- 深色模式下透字对比更刺眼（`r4_04_dark_library.png`：浅色幽灵字+深色玻璃）
- 出现位置：迷你条+底部导航（曲库页任意滚动位置），跨主题色/深浅色稳定复现（r1_02 / r3_01 / r4_01 / r4_04 / r4_05）
- 修法方向修正：不是 `!hazed` 兜底问题，是 chrome 层 scrim/不透明度需加强（或透字区加磨砂加重档）

### F2【P2·观察】媒体会话封面私有路径
- logcat：system(pid 4936) 反复 `EACCES: /storage/emulated/0/Android/data/com.local.music.debug/cache/covers/*.png`
- 代码：`MusicPlaybackService.toMediaItem():267 setArtworkUri(externalCacheDir 路径)`
- 实际影响：控制中心媒体卡/锁屏组件封面**渲染正常**（走通知 bitmap 通道）；但私有路径对外暴露持续刷系统 E 日志，且依赖该路径的第三方面板（车载/手表等）拿不到封面。建议 metadata 改用 content URI 或内嵌 bitmap

### G1 复查（闭环确认）
- 90dp 保护带按设计生效：带内歌词强衰减（近顶部近隐、中段半衰），无全不透明歌词穿越小封面（`r4_02_lyrics_g1.png`）；残留观感：带内中段（~73dp）半透明文字与封面右缘轻微交叠，可辨度低，不构成遮挡

## 4. 环境与工具坑（后续真机测试必读）
- **USB adb 掉线 ×2**（10:08、10:13，各 ~2.5min 自愈/重插恢复）——长等待测试要把「设备在位检查」放进循环
- `input text` 不能输中文（NPE）；ColorOS 键盘会给英文输入**自动补「, 」**；`input keyevent 67`(DEL) 在该键盘上不可靠
- `adb push` 中文长文件名被**截断**（`...You Lea`）——.lrc 测试优先用 ASCII 名，或推后逐字节核对 `ls`
- `media volume`/`cmd media` 在 ColorOS 不存在；媒体控制用 `input keyevent 126/127`
- 锁屏无 PIN：触摸即解锁；锁屏上 `input tap` 会穿透到 App（锁屏控件测试改用 media keyevent）
- 截图恒 1440×3168 可直用；`dumpsys media_session` 陈旧值坑再现（本轮全程改用截图+`dumpsys audio` players 状态）
- 定时器观察不能只看 AudioTrack state（暂停后变 idle）；看快照 `sleepTimerMode` + 时间窗判别
